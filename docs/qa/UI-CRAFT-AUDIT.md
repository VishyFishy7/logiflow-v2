## What I verified as correct

1. **PageHeader on every screen** — all 14 authenticated screens + login use the shared `PageHeader` component with consistent title scale and action slot placement. ✓
2. **Accent colour discipline** — no raw hex values in any component file; no raw Tailwind palette classes (`bg-blue-500`, etc.) in pages or components. All colour comes from CSS tokens via `globals.css`. ✓
3. **Green reserved for success** — `--status-delivered`, `--status-won`, `--status-paid` use green tokens; no screen uses green as an accent or general colour. ✓
4. **No raw `<table>` elements** — the only `<table>` in the codebase is in the vendored chart engine (sr-only for accessibility). ✓
5. **DataTable used for most list surfaces** — shipments, invoices, clients, carriers, and the leads table view all use `DataTable`. ✓
6. **Empty vs filtered-empty differentiation** — shipments and leads correctly show different empty states with "Clear filters" action when filters are active. ✓
7. **StatusBadge consistency** — the shared `StatusBadge` component is used across all screens; tones come from `lib/format.ts` which reads tokens. ✓
8. **ResponsiveOverlay / ConfirmDialog** — destructive actions (delete shipment) use `ConfirmDialog`; forms use `ResponsiveOverlay`. ✓
9. **URL-backed filters** — shipments and leads use `useListState` for URL-synced filter state. ✓
10. **SectionCard / DetailField** — shared layout components used consistently across detail screens. ✓
11. **Focus ring visible** — `globals.css` defines `:focus-visible { outline: 2px solid var(--ring); outline-offset: 2px; }` globally. ✓
12. **Skip-to-content link** — present in `app-shell.tsx` line 51–56. ✓
13. **prefers-reduced-motion** — handled in `globals.css` (lines 295-304) and `MotionConfig reducedMotion="user"` in app-shell. ✓
14. **h-dvh used in app shell** — `min-h-dvh` on the root container and `h-dvh` on the sidebar. ✓
15. **Icon-only buttons have aria-labels** — the CopyButton in shipment detail has `aria-label={`Copy ${label}`}`. ✓
16. **Token layer completeness** — `globals.css` defines dual-theme tokens for all status hues, severity levels, charts, and sidebar. ✓
17. **MotionConfig** — `reducedMotion="user"` wraps the entire app shell. ✓
18. **DataState used on every screen** — all 14 pages import and wrap content with `DataState`. ✓
